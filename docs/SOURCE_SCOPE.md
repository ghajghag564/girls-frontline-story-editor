# 0.1.27-rc.7 源码范围

本源码版提供本地服务、浏览器编辑界面、剧情时间轴、人物绘制与模型计算、工程存储、音频混合及 MP4 导出。应用从外部配置读取素材和运行组件，将写入留在独立的工作区。 [配置方法](LOCAL_ASSETS.md)

| 模块 | 源码版行为 |
| --- | --- |
| 人物渲染 | WebGL 网格、透明混合、遮罩、贴图、舞台定位与表情切换。MOC3 求值在单独的模型进程中执行。 |
| 人物动画 | 编辑器用通用算法计算表情过渡、眨眼与标点口型。默认构图由素材可选配置提供，已保存位置按工程读取。 |
| 背景与字幕 | PNG 底图、工程转场与场景色调。旁白框由 Canvas 绘制，字体来自操作系统。 |
| 教程与示例 | 通用九步教程。用户有权使用的本地工程可通过配置作为示例。 |
| 导出 | 本地 FFmpeg 负责 H.264 或 H.265 编码与 AAC 音轨。具体编码取决于使用者配置的 FFmpeg。 |

素材目录仅索引本机已有的 MOC3、PNG 和 FLAC 文件。工程、素材和依赖路径通过独立的本地配置指定。 [本地配置](LOCAL_ASSETS.md) · [第三方依赖与许可](../THIRD_PARTY_NOTICES.md)

`source-manifest.json` 包含拟发布文件的 SHA-256。修改源码或文档后可用 `node scripts/build-manifest.mjs` 更新，并执行 `node scripts/verify-manifest.mjs` 和 `node scripts/check.mjs`。
