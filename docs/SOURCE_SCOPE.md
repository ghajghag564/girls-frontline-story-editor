# 0.1.50 源码范围

本源码版提供本地服务、浏览器编辑界面、剧情时间轴、人物绘制与模型计算、工程存储、音频混合及 MP4 导出。应用从外部配置读取素材和运行组件，将写入留在独立的工作区。 [配置方法](LOCAL_ASSETS.md)

| 模块 | 源码版行为 |
| --- | --- |
| 人物渲染 | WebGL 网格、透明混合、遮罩、贴图、舞台定位与表情切换。MOC3 求值在单独的模型进程中执行。 |
| 人物动画 | 编辑器用通用算法计算表情过渡、眨眼与标点口型。默认构图由素材可选配置提供，已保存位置按工程读取。 |
| 背景与字幕 | PNG 底图、静音循环视频背景、过场视频与场景色调。游戏原版布局由 Canvas 绘制。小剧场字幕支持角色名、台词和竖线配色。两种模式共用工程保存的字形设置。 |
| 教程与示例 | 四步快速上手和通用九步详细教程。配置了本地示例时使用练习副本，空素材目录可用程序生成的纯色对白练习。 |
| 本地音频 | 从「音乐」面板导入并试听浏览器支持的音频，保存在工作区。预览和导出共用作品的音乐时间轴。 |
| 导出 | 通过外部配置使用 Windows Media Foundation 调用程序或 FFmpeg。优先尝试本机 Windows 编码器，支持所选档位时输出 MP4 和 AAC 音轨。调用程序源码可自行构建。 |

素材目录索引本机已有的 MOC3、PNG、FLAC 和已配置的字体。界面导入的视频保存在独立工作区。工程、素材和依赖路径通过本地配置指定。 [本地配置](LOCAL_ASSETS.md) · [第三方依赖与许可](../THIRD_PARTY_NOTICES.md)

`source-manifest.json` 包含拟发布文件的 SHA-256。修改源码或文档后可用 `node scripts/build-manifest.mjs` 更新，并执行 `node scripts/verify-manifest.mjs` 和 `node scripts/check.mjs`。
